# アイデアピッチ用デモ集

アイデアピッチで企画や体験を審査員に伝えるためのデモをまとめたリポジトリです。特定の企画だけの置き場ではなく、複数のアイデアピッチ用デモを、それぞれ独立したページとして管理します。

## デモ一覧

| 企画 | 内容 | 公開ページ | 配置 |
| --- | --- | --- | --- |
| 私が、店主です。 | NFC店主カードの体験を伝えるプロトタイプ | [デモを見る](https://yossi0413.github.io/owner-card-demo/) | `index.html` |
| 土地も歩けば紀行文にあたる | 写真の展示からQRで紀行文を読む体験。掲載作品は「体の髄まで」（ヨッしー） | [デモを見る](https://yossi0413.github.io/owner-card-demo/kikoubun/) | `kikoubun/index.html` |

## 位置づけ

各ページはアイデアピッチの説明・審査に使用するデモです。実際に閲覧・操作できるページとして公開していますが、企画全体の正式サービス開始や継続運用、採用・受賞実績を示すものではありません。

デモであることの説明はこのREADMEにまとめ、審査員が見る各ページや印刷物は企画の体験を伝える構成にしています。
