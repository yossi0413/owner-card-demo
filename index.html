手のひらに、ひとりの店主。

カード表裏 / 63 × 88 mm。画像を保存して、スライドにそのまま載せられます。

印刷：A4・倍率100%・ヘッダー/フッターなし・背景グラフィックあり。2枚を切り抜き、NFCシールを挟んで貼り合わせます。両面印刷用の面付けではありません。印刷後に定規で寸法を確認してください。

① 店主・店舗情報を差し替える

このHTMLをテキストエディターで開き、末尾の const SHOP を編集します。実際の店主・店舗の了承を得て内容を確認し、demo: false に変更。住所、営業時間、価格、アレルギーは店舗確認済みの情報を記入してください。イラストも架空の人物です。実在の店主に合わせて差し替えてください。

データを増やす必要はありません。店主の変な情報3つ＋最低限の店舗情報だけで成立する試作です。

② GitHub Pagesで公開する
  1. GitHubで公開用リポジトリを作成します。
  2. このファイルを index.html の名前でリポジトリ直下にアップロードします。
  3. Settings → Pages → Deploy from a branch → main / (root) → Save。
  4. Pagesに表示された公開URLをスマホで開き、表示と地図リンクを確認します。
  5. この欄に公開URLを入力し、NFC書き込み用にコピーします。

カードの制作画面は、公開URLの末尾に ?mode=studio を付けて開けます。公開URLが変わらなければ、HTMLを更新してもNFCの書き直しは不要です。

③ NFCカードを作る
  1. NFC書き込みアプリで、URL/URI形式のレコードを選びます。
  2. 公開URLを書き込みます。HTML本体や制作画面のURLは書き込みません。
  3. スマホで読み取り、店主ページが開くことを確認します。端末によっては通知のタップが必要です。
  4. 表裏を印刷し、NFCシールを挟んで貼り合わせます。
  5. 完成後にもう一度読み取ります。試作中はタグを読み取り専用にロックしないでください。
